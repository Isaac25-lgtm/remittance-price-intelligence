# Changes versus frozen phase 1

Legacy definitions and outputs are not replaced. Phase 2 adds chronological validation/calibration, group transfer, time/crossed dependence sensitivities, explicit observation selection, threshold/basket/identity robustness and literature/release evidence. These are retrospective extensions, not confirmation.

Software corrections planned before phase-2 metrics: make reproduction fail on scientific table differences; compare only genuinely regenerated tables; enforce UTF-8 on text reads; align dashboard dependencies with APIs; validate source provenance. None changes the legacy scientific specification. Reproduction differences caused by dependencies are measured and reported.

Potential cleaning alternatives are separate named sensitivities: use actual collection quarter for out-of-quarter records, transparent-only prices, exclude negative FX margins, and remove access/location metadata from identity only with uniqueness/collision audit. Expected direction is not assumed. Affected counts are generated from the source audit before interpretation. The original quote-total cost and period label remain the primary legacy convention.
